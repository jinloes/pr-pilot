- Security: report an injection or authorization finding only when you can name the caller-controlled source (a request parameter, header, body, path segment, message, or uploaded file) and the changed line where it reaches the sink, or the sibling handler whose check the new code omits. Report the other classes only when the changed line itself shows the weakness.
  - Authorization: an endpoint, handler, RPC, job, or query that acts on a caller-supplied identifier without the ownership, tenant, or permission check its siblings perform, or a new query missing the tenant filter its siblings apply.
  - Deferred authorization: a reachable endpoint, handler, or RPC that returns another party's data or performs a write after authenticating the caller but without the permission or capability check it needs, with that check left to a TODO, ticket, or follow-up. A tracked deferral does not make it safe to ship: until the follow-up lands, any authenticated caller can use it. Report it unless a flag, missing route, or unwired caller keeps it unreachable; tell the author to enforce the check before any data is read, or to keep the endpoint unreachable until it is.
  - Injection: caller-controlled data reaching SQL or a raw ORM query, a shell or process argument, a template or HTML response, a file path (path traversal, an archive entry extracted without a path check), an outbound URL or host (server-side request forgery), a regular expression, or an LDAP or XPath query, without parameterization, escaping, or an allow-list.
  - Unsafe deserialization: untrusted input read through Java serialization, polymorphic JSON typing (Jackson default typing, or @JsonTypeInfo keyed by class name), pickle, BinaryFormatter, or yaml.load without a safe loader.
  - Secrets and cryptography: a hard-coded credential or key; a token, password, or identifier generated with a non-cryptographic random source; a password hashed with a fast or unsalted hash; TLS certificate or hostname verification disabled; a JWT accepted without verifying its signature, algorithm, audience, and expiry; CORS that reflects any origin while allowing credentials; a secret compared with a non-constant-time equality check.
  - Error exposure: an exception message, stack trace, SQL statement, or internal host or path returned to an external client in an error response.
  Do not report generic hardening that has no such evidence, such as a missing rate limit, a theoretical denial of service, or input validation with no demonstrated sink.
